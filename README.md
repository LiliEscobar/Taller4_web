# Taller4_web

## Proyecto inicial

Frontend con Vite, React y Reactstrap.

```bash
cd frontend
npm install
npm run dev
```

Abrir la dirección que indique Vite en la terminal.

## Backend

En otra terminal, desde la raíz del repositorio:

```bash
cd backend
npm install
npm run dev
```

Consultar la API en http://localhost:3005/api.
